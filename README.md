## 🌟 解决真实教学问题，为什么孩子们喜欢它？

### 1. 顺着孩子往下聊，绝不生硬逼问
传统的教学软件总是一板一眼地问：“第一幅画是什么？第二幅画是什么？” 只要孩子多说两句就被打断。  
**故事小精灵就像一位懂孩子的温柔幼师**：
- 孩子要是胆子大、一口气把故事讲全了，老师立刻拍手大力夸奖，并好奇地追问一个更有趣的问题；
- 孩子要是害羞只讲了半句，老师就先肯定他说得对，再温和地拉着他看下一幅图；
- 孩子如果卡壳想不起来，老师只在图里圈出线索提醒，绝不替孩子直接把答案说破。

### 2. 彻底去掉“AI 机械电音”，换上自然好听的真人声音
普通软件的声音硬邦邦的，像新闻播报员，小孩子听两句就觉得无聊。  
我们精选了 **4 位性格不同、声音柔和自然的好老师**（默认推荐：小晨老师自然口语），把语速放慢到最适合小朋友听懂的节奏，说话就像大姐姐坐在旁边笑眯眯地聊天。

### 3. 一目了然的干净界面，没有任何杂乱表情符号
不用花里胡哨的 Emoji 表情干扰幼儿注意力。底部的录音麦克风是清清爽爽的矢量图标，孩子小手一按就能说话，松开就能发送，3 岁小班娃娃也能自己拿手指操作。

### 4. 讲完故事发大奖杯，出具能力小报告
孩子讲完故事，屏幕上会绽开五彩礼花，跳出一座闪亮的大奖杯，告诉孩子获得了“看图讲故事小达人”荣誉！还会给老师和家长生成一份观察力、表达力和连贯性的小结，点击还能听孩子自己的口播录音。

### 老师如何快速在自己电脑上运行？
1. 安装 Node.js；
2. 下载代码：
   ```bash
   git clone https://gitee.com/cpt11/teach.git
   cd teach
   npm install
   npm run start
   ```
3. 打开电脑浏览器访问 `http://localhost:3000` 即可开始使用。
