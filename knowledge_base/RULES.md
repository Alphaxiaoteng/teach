# 幼儿看图讲故事 Agent 规则（轻量版）

## 1. 产品边界

目标不是“AI 会讲故事”，而是“孩子能自己讲出来”。系统只有四个状态：选故事、逐图引导、卡壳提示、原话回放。图片标签属于教师侧私有事实库，不能直接显示为答案。

## 2. 分龄规则

| 年龄 | 图片 | 重点 | 单轮问题 |
|---|---:|---|---|
| 小班 3–4岁 | 1–2张 | 谁、做什么 | 不超过20字，只问一件事 |
| 中班 4–5岁 | 2–3张 | 谁、哪里、做什么、先后变化 | 不超过28字 |
| 大班 5–6岁 | 4张 | 时间、地点、角色、行动、表情/想法、结果 | 不超过36字 |

## 3. 防代答机制

正常提问和“给我线索”只读取每张图人工审核过的 `visual_clues`。`private_annotations.visible_summary` 与标签只帮助系统理解图片，禁止直接念给孩子。第一次卡壳提示观察位置/颜色/数量；第二次提示手边物体或动作；第三次允许跳过，不公布标准答案。

## 4. 事实与推测

- 角色、物体、动作、地点、可见表情属于画面事实。
- 原因、想法、角色关系和下一步通常属于推测，应使用“你觉得”“可能”。
- 如果标题与图片冲突，以图片为准并标记 `title_content_mismatch`。
- 如果画面顺序不支持明确因果，只引导比较变化，不自动补故事。

## 5. 完成与回放

每张图获得一次有效讲述后进入下一张；教师可明确跳过。回放只按图序连接幼儿原话，可补标点和最少连接词，不新增角色、事件、结果或“标准答案”。评价只指出具体优点，不打分、不排名、不和别的孩子比较。

## 6. 素材质量与安全

所有 58 个故事均进入目录；带 `teacher_review_required` 的故事在封面显示待复核标识。血迹、明火、热水、碎片等内容触发教师陪同与安全表达：不强化刺激细节，不鼓励模仿，优先引导远离危险、找成人帮助。

## 7. 模型边界

云端模型不是核心依赖，只允许润色最终回放和正向反馈；不能生成线索、修改人工标签或增加孩子没说过的情节。断网或未配置模型时，本地 HTML + 规则引擎仍应完整可用。
