# 《故事小精灵》幼儿看图讲故事智能体
## 产品需求与功能规格说明书 (PRD V2.0)
**文档版本：** V2.0（迭代自星洋智慧 V1.0 架构）  
**面向对象：** 评审专家 / 幼儿园教师 / 3-6 岁幼儿及家长  
**产品定位：** 具备儿童心理学启发情商、物理事实锁与超自然拟人音色的 AI 绘本伴读系统  

---

### 一、产品背景与核心升级 (Why V2.0)

星洋智慧在 V1.0 初版中提出了基于 Coze 搭建幼儿讲故事的初步构想。但在真实落地与课堂测试中发现了四大瓶颈：
1. **Coze 平台通用 Agent 易产生事实幻觉**：通用大模型容易脱离画面瞎编；
2. **机械逐图逼问**：不管孩子说了什么，生硬要求“先讲第1张再讲第2张”，打击孩子表达积极性；
3. **合成音充满冷冰冰的“AI 播音腔”**：儿童难以建立面对面倾听的信任感；
4. **Emoji 符号堆叠产生视觉干扰**：幼儿注意力易被杂乱图标分散。

**V2.0 终极工程升级：**
摆脱三方无代码平台的框架限制，完全基于全栈自主架构自研。打造**多模态事实锁 (Fact-Lock)**、**自适应支架教学状态机**、**生活化自然名师音色**与**极简现代矢量 UI**。

### 三、详细功能规格矩阵

#### 3.1 模块一：分龄适性绘本馆 (Age-Adaptive Library)
- **班级选择器**：小班（2幅简易图，20本）、中班（2-3幅情节图，20本）、大班（4幅时序图，18本）；
- **动态换一批**：采用 Fisher-Yates 洗牌算法，毫秒级无感知切换推荐画册；
- **高清大图检视**：轻触任意画幅触发全屏视口沉浸放大，支持双指缩放查看细节。

#### 3.2 模块二：AI 启发式讲故事带教台 (Socratic Dialogue Console)
- **双图/四图时间脉络大屏**：分幅大图自适应排版，带编号指示器；
- **无 Emoji 纯净交互**：录音按钮全量使用专业 SVG 矢量图形，录音时呈现波形指示，杜绝 Emoji 干扰；
- **双模输入无缝切换**：支持语音一键极速识别（ASR）与键盘打字（拼音 IME 友好）；
- **实时点赞徽章**：每轮交互实时展示【🎯 准确度点赞徽章】（如“精准捕捉到了小兔子分享的关键细节！”）。

#### 3.3 模块三：超自然生活化名师声线库 (Lifelike Voice Personas)
- 🌿 **小晨老师（默认推荐）**：台湾生活化自然口语女声，咬字温柔、语气轻快自然，零 AI 播音腔；
- 🌸 **晓晓老师**：经典特级名师声线，语调温润亲切，充满包容感；
- 🧸 **依依姐姐**：元气活泼的绘本电台主播，热情伴读；
- 🍁 **小雨姐姐**：慢速知性大姐姐，舒缓治愈陪伴。

#### 3.4 模块四：结业荣誉与学情能力报告 (Achievement & Evaluation)
- **全屏 Confetti 礼花粒子**与金色跳动大奖杯；
- **三维能力量化评估卡**：
  - 【细节观察力】：是否发现关键道具、背景细节与隐蔽线索；
  - 【语言表达力】：词汇丰富度、句式完整性与修辞运用；
  - 【逻辑连贯度】：前后因果衔接、时间先后次序与结局闭环；
- **专属荣誉称号授予**（如“看图表达小能手”、“爱心小天使”）。
