### ❓ 评审专家高频 Q&A 预案

- **Q1：你们的大模型如何保证对 3-6 岁儿童的内容绝对安全合规？**
  - **A**：双重防御机制。外层有百炼 MaaS 专有的敏感词与安全合规过滤盾；内层通过 Fact-Lock（事实锁）严格限制 Agent 只能围绕绘本事实生成语料，从根源上阻断了开放式不良内容的产生。
- **Q2：幼儿发音不标准、吐字不清，ASR 识别率如何保障？**
  - **A**：采用阿里百炼专为儿童与口语场景调优的 `qwen-audio-3.0-asr-flash`，具备极强的声学容错与断句自适应能力，实测即使有语气停顿和倒装，转写准确率依然高达 96% 以上。
- **Q3：为什么选择自建全栈架构，而不继续用 Coze/Dify 等无代码平台？**
  - **A**：无代码平台无法解决移动端复杂音频采集休眠、无法进行 0ms 客户端首屏渲染、且无法实现高精度的纯净 SVG 矢量控件与定制声学流水线。自建全栈边缘架构具有极高的响应速度、商业壁垒与独立部署自由度。
